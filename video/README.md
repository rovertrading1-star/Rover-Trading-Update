## Using it

- **Website hero / course page:** embed with `<video src="video/rover-trading-walkthrough.mp4" controls poster="video/thumbnail.jpg"></video>`.
- **YouTube / socials:** upload the MP4 and attach the `.srt` for captions.
- **WhatsApp / email:** the file is under 10 MB, so it sends without compression.

The video was recorded from the live site with the brand fonts applied, so on-screen text matches the real design.
